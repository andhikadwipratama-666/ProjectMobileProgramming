# 💳 Project Mobile Programming - E-Wallet App

Aplikasi dompet digital (*E-Wallet*) berbasis Android yang dikembangkan menggunakan **Kotlin** dan **Jetpack Compose** dengan menerapkan arsitektur **2 Activity** (`MainActivity` untuk autentikasi/input data dan `DetailActivity` sebagai pusat dashboard transaksi).

* **Nama:** Andhika Dwi Pratama

---

## 🚀 Fitur Utama Aplikasi
1. **Arsitektur 2 Activity & Intent:** Pengiriman data pengguna (Nama, Nomor HP, dan PIN) dari halaman login ke halaman dashboard secara mulus menggunakan `Intent`.
2. **Dashboard E-Wallet Estetik:** Tampilan antarmuka modern ala *FinTech* menggunakan sudut kartu melengkung (*Rounded Corner*) dan palet warna profesional.
3. **Tombol Privasi Saldo (Privacy Toggle):** Fitur untuk menyembunyikan atau menampilkan nominal saldo (`👁️ Sembunyikan` / `🔒 Tampilkan`) demi keamanan privasi di tempat umum.
4. **Top-Up & Transfer Saldo Real-Time:** Simulasi penambahan saldo dan pengiriman uang ke nomor HP lain yang langsung memotong/menambah saldo secara akurat.
5. **Verifikasi PIN Keamanan (Security Dialog):** Setiap transaksi penting (Top-Up & Transfer) wajib melewati dialog konfirmasi PIN rahasia yang dicocokkan dengan data akun.
6. **Pencarian Riwayat Cerdas (Search Bar):** Kolom pencarian interaktif untuk menyaring riwayat transaksi berdasarkan kata kunci secara instan.
7. **Widget Ringkasan Finansial:** Kartu informasi kecil di atas riwayat untuk memantau status aktivitas dompet.
8. **Riwayat Berwarna Dinamis:** Indikator transaksi otomatis dengan warna **Hijau** untuk pemasukan (Top-Up/Aktivasi) dan warna **Merah** untuk pengeluaran (Transfer).

## 📱 Panduan Menjalankan Project
1. Clone atau *download* repository ini ke komputer/laptop.
2. Buka aplikasi **Android Studio**.
3. Pilih **Open an Existing Project** dan arahkan ke folder project ini.
4. Hubungkan perangkat HP Android ke laptop (pastikan **Opsi Pengembang / Developer Options** dan *USB Debugging* sudah aktif di HP).
5. Klik tombol **Run (▶)** berwarna hijau di Android Studio untuk memasang dan menjalankan aplikasi ke perangkat.
